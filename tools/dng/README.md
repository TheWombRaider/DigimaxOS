# tools/dng (placeholder)

A host-side converter from authentic pre-JPEG sensor data to DNG (RAW-01, P1). Nothing is
implemented, because no RAW readout path has been identified. Requirements before any code:
the documented CCD readout path, packing, bit depth, CFA pattern, black/white levels and optical
black, all from real captures. A JPEG must never be renamed or re-encoded and passed off as RAW.
